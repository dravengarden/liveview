# `app/` — the native shell (Tauri): iOS · macOS · Android

One Tauri project drives every native platform; the PWA is the same SPA served by
the server without a shell. This directory is the single source of truth for the
native application.

```
app/
├── src-tauri/                the Tauri project root (tauri.conf.json, Cargo.toml, src/)
│   ├── src/host.rs           thin `lvsync://localhost` overlay / origins / host-info
│   ├── gen/apple/            iOS  (xcodegen project + Swift Sources: bridges, AVPlayer)
│   │   └── …/Sources/liveview-app/   NativeAudioController (Swift media cache + AVPlayer)
│   ├── gen/android/          Android — GENERATED by `cargo tauri android init` (not yet)
│   ├── capabilities/         Tauri ACL for the bundled and OTA app origins
│   └── icons/                app icons (incl. android/)

../web/                       the shared SPA — `deno task build:app` → web/dist-app,
                              bundled here as frontendDist. NO service worker.
                              Content replica lives in TypeScript IndexedDB.
../tools/lvbuild*.sh          device + simulator build/install scripts
```

## Platforms

| Platform | How | Offline shell | Data layer |
|---|---|---|---|
| **iOS** | `cargo tauri ios build` (gen/apple) | bundled SPA (dist-app), local origin, no SW | TS IDB replica + thin `lvsync://` host + native AVPlayer (Swift) |
| **macOS** | `cargo tauri build` (desktop) | bundled SPA, local origin, no SW | TS IDB replica + thin `lvsync://` host |
| **Android** | `cargo tauri android build` (gen/android — future) | bundled SPA, no SW | TS IDB replica + thin `lvsync://` host |
| **PWA** | served by the server (`web/dist`) | service worker | fetch + SW + TS IDB replica |

## Android (future, dir reserved)

Android shares the thin `lvsync://` host and the same bundled SPA — no second
content store. To bring it up: `cargo tauri android init` (creates
`src-tauri/gen/android/`), then `cargo tauri android build`. Audio: Android
MediaSession (native) or the web `<audio>` element. The capabilities already
work cross-platform.
