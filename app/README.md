# `app/` — the native shell (Tauri): iOS · macOS · Android

One Tauri project drives every NATIVE platform; the PWA is the same SPA served by
the server (no shell). This is the single source of truth for the app — the old
divergent `tauri-shell` branch + the stale Mac `~/liveview-shell` working copy are
retired in favour of this (see `docs/offline-rearchitecture.md`).

```
app/
├── src-tauri/                the Tauri project root (tauri.conf.json, Cargo.toml, src/)
│   ├── gen/apple/            iOS  (xcodegen project + Swift Sources: bridges, AVPlayer)
│   │   └── …/Sources/liveview-app/   LvSyncController, NativeAudioController (Swift)
│   ├── gen/android/          Android — GENERATED by `cargo tauri android init` (not yet)
│   ├── capabilities/         Tauri ACL (local-origin = bundled SPA; remote-* = legacy)
│   └── icons/                app icons (incl. android/)
└── loader/                   legacy remote-probe page (dropped once bundled, A3)

../plugins/lvsync/            shared cross-platform Rust Tauri plugin (the offline
                              data layer: Merkle + resolve + SQLite index + retention)
../web/                       the shared SPA — `deno task build:app` → web/dist-app,
                              bundled here as frontendDist (A3). NO service worker.
../tools/lvbuild*.sh          device + simulator build/install scripts
```

## Platforms

| Platform | How | Offline shell | Data layer |
|---|---|---|---|
| **iOS** | `cargo tauri ios build` (gen/apple) | bundled SPA (dist-app), local origin, no SW | `plugins/lvsync` (Rust) + native AVPlayer (Swift) |
| **macOS** | `cargo tauri build` (desktop) | bundled SPA, local origin, no SW | `plugins/lvsync` (Rust) |
| **Android** | `cargo tauri android build` (gen/android — future) | bundled SPA, no SW | `plugins/lvsync` (Rust) |
| **PWA** | served by the server (`web/dist`) | service worker | fetch + SW |

## Android (future, dir reserved)

Android shares everything native via the cross-platform Rust plugin
(`plugins/lvsync`) and the same bundled SPA — no new data layer needed. To bring
it up: `cargo tauri android init` (creates `src-tauri/gen/android/`), then
`cargo tauri android build`. Audio: Android MediaSession (native) or the web
`<audio>` element. The capabilities + plugin already work cross-platform.
