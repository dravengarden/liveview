One content contract

From source to shelf,
intact.

Preview, checking, publication, web reading, and native sync share one set of parsing rules. The content you checked is the content your reader receives.

liveview — quick start 
# 1 · Build
$ git clone https://github.com/dravengarden/liveview.git
$ cd liveview && nix build

# 2 · Preview any folder, no services
$ cd /path/to/your/library
$ /path/to/liveview/result/bin/liveview preview --open
✓ Serving library at http://127.0.0.1:4160

# 3 · Check before you publish
$ /path/to/liveview/result/bin/liveview check . --deny-warnings
