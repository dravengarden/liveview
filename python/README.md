# liveview

Fast live-reloading file previewer for Markdown, images, PDFs and more.

## Installation

```bash
pip install liveview
```

## Usage

```bash
# Preview current directory
liveview

# Preview a specific file
liveview README.md

# Open browser automatically
liveview -o
```
